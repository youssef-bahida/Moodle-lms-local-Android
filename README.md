## 📖 About

**Bitnami LMS Moodle** is a ready-to-deploy Moodle Learning Management System packaged as a virtual machine.

The project aims to simplify the deployment of a complete Moodle environment by providing a preconfigured server that can be imported into virtualization software such as **VirtualBox** or **VMware**.

Instead of manually installing and configuring every component, you can use an already prepared environment.

### 🏗️ Architecture

```text
Host Computer
     |
     v
VirtualBox / VMware
     |
     v
Moodle Virtual Machine
     |
     +---- Bitnami
     |
     +---- Moodle
     |
     +---- Web Server / PHP
     |
     +---- Database
     |
     v
Moodle Web Interface
     |
     +---- Teachers
     |
     +---- Students
```

- Follow the installation instructions carefully.
- Verify your device architecture before restoration.
- Make sure you have sufficient storage space.
- Do not delete existing backups or containers during installation.
- Keep your administrator credentials private.
- This environment is intended for local use unless additional network and security configuration is performed.
